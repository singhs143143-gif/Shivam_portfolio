# Portfolio Application

A frontend-only React portfolio built with Vite, TypeScript, and Tailwind CSS.

## Commands

```bash
pnpm dev
pnpm build
pnpm typecheck
pnpm test
```

## Structure

- `client/` contains the React application.
- `client/pages/Index.tsx` is the portfolio homepage.
- `client/global.css` contains the visual theme.
- `vite.config.ts` configures the frontend build.
- `dist/` is the static production output for Vercel.
